
# Luna Café ☕

A modern café website built using HTML and CSS.

## Features

- Responsive design for desktop and mobile
- Clean and elegant café-themed UI
- Navigation bar
- About section
- Menu cards
- Image gallery
- Contact form
- Footer section

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Project Preview

A simple and modern website concept for a café brand with warm colors and a minimalist style.
